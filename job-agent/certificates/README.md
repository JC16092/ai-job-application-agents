# Certificates

Put your certificate / licence PDFs here (for example: RSA, First Aid, Working with Children Check, driver's licence) so an agent can upload them when an application form asks for one.

- Name them clearly, e.g. `RSA_Certificate.pdf`, `First_Aid.pdf`.
- **PDFs in this folder are git-ignored by default** (see the repo's `.gitignore`), so your real certificates will not be committed or published.
- Only add documents you're comfortable uploading to employers you apply to.
